NACFE Knowledge Base — embed demo

This page shows exactly what publishers embed: a <div id="nacfe-assist"> mount point plus one <script> tag. Everything below is rendered by widget.js — no other markup on this page touches it. This demo loads the local copy of widget.js (for iterating on changes before deploying) but talks to the real, live query API — the actual production embed loads widget.js from the Worker itself instead; see README.md.
